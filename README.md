# Система поиска клиентов

Личный проект Stas'а (не клиентский). Цель: собрать работающую систему, которая стабильно приводит заказы на сайты и Telegram-ботов.

**Рынок:** сначала СНГ, потом зарубеж.
**Бюджет:** до ~1000 руб/мес.
**Время:** 5–10 часов в неделю.
**Активы:** 3 выполненных проекта (лендинг коуча, TG-бот Ольги, прелендинг Константина).

## Структура

- `RESEARCH.md` — что выяснили про три предложенных варианта и другие каналы, с источниками
- `PLAN.md` — пофазный план с задачами и метриками
- `tracker/` — рабочая папка: источники, шаблоны откликов, статистика (появится при реализации)

## Статус

🟡 Фаза 0 — план составлен, начинается разведка источников.
