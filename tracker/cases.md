## Кейс 2. Telegram-бот-воронка для специалиста по Синельникову

**Кто заказчик:** Ольга, метапсихолог, тренер (Instagram-аккаунт).
**Статус:** разработка завершается, к запуску. `[?]` запущен ли уже.

**Задача:** провести человека из Instagram в Telegram и довести до заявки на консультацию
без давления — прогревающей серией постов.

**Что сделано:**
- бот на aiogram 3 + SQLite: `/start` → серия из 8 постов по таймингам заказчицы;
- серия останавливается, как только человек сам проявил активность (нажал кнопку или написал);
- под постами кнопки «Задать вопрос» и «Запись»: вопрос уходит админам уведомлением,
  запись — анкета (имя → контакт → время) с валидацией полей;
- `/leads` — просмотр заявок; тексты вынесены в отдельный файл, заказчица может править сама;
- переживает перезапуски: расписание и пропущенные посты восстанавливаются.

**Результат:** `[?]` сколько заявок после запуска.

**Чем полезно заказчику:** серия работает, пока специалист занят; заявки не теряются.

## Кейс 3. Прелендинг под рекламу Facebook

**Кто заказчик:** Константин, проект «Анти-грабли».
**Ссылка:** https://justik01.github.io/antigrabli/

**Задача:** страница-прокладка для рекламного трафика: зацепить, провести дальше
в Telegram-бота, корректно отчитаться рекламному кабинету.

**Что сделано:**
- одностраничник на HTML/CSS/JS;
- обход ограничения рекламы: текст страницы и мета-теги вычищены от упоминаний
  мессенджера, кнопка ведёт напрямую в бота;
- Meta Pixel: событие Lead отправляется с задержкой ~700 мс — beacon успевает уйти
  до перехода на другой домен; если пиксель блокирует adblock, кнопка просто работает;
- решение по переходу: промежуточная страница Telegram не показывается.

**Результат:** `[?]` CPL / количество переходов / заявки.

**Чем полезно заказчику:** реклама не сливает бюджет из-за ошибок в отчётности.

## Итого для портфолио

Три разные задачи: визитка (дизайн+деплой), бот (логика+база+воронка),
рекламная страница (конверсия+аналитика). Этого хватает, чтобы закрыть типовые
запросы «сделай сайт» и «сделай бота».
